Kitchen Chaos is a small single player cooking simulator game created in Unity in the style of Overcooked.
I followed Code Monkey's [intermediate Unity course](https://www.youtube.com/watch?v=AmGSEH7QcDg) and used clean coding practices throughout.
While working on this project I learned how to make a character controller, handle collisions and interactions, C# events and interfaces, shader graph, input system, loading, state machines and much more.
