# 🍳 Kitchen Chaos

**Kitchen Chaos** is a small single-player cooking simulator game created in Unity, inspired by *Overcooked*. The project was developed by following [Code Monkey](https://www.youtube.com/@CodeMonkeyUnity)'s [intermediate Unity course](https://www.youtube.com/watch?v=AmGSEH7QcDg) while adhering to clean coding practices.

---

## 🎮 Features & Learnings
- Developed a cooking simulation game using **Unity**.
- Reinforced **object-oriented programming (OOP)**, **separation of concerns**, and **event-driven programming**.
- Implemented **inheritance**, **interfaces**, and **state machines** for structured gameplay logic.
- Used **C# events, delegates, and lambda functions** for decoupled communication.
- Applied the **Singleton pattern** and **Scriptable Objects** for efficient data management.
- Built a **responsive, controller-compatible UI** with Unity’s new Input System.
- Strengthened skills in **clean architecture** and **modular design**.
- Explored **shader graph**, **collision handling**, **character controllers**, and **game state management**.
